# 发布验收记录 · 0.7.0-chat.1

日期：2026-10-16。Windows x64，Python 3.12.7，Node.js 24.19.0，Electron 44.4.5，Playwright 1.63.0。

## 已验证

- 隔离空副本初始化；默认仅聊天在已加载工具列表，未复制个人数据和权限状态。
- 规范审计、资源目录、能力目录、环境观察等基础 API 可用；聊天通过正式工具打开接口进入，未绕过规范门禁。
- 前后端目录分离；真实 Electron 启动前端并连接后端，聊天和模型设置实际可操作。
- 聊天保存、停止、解除加载、扫描发现与重新加载；工作台状态和聊天历史重新打开后保留。
- 本机人工 HTTP 模型通过原 AI 总控完成一次真实请求往返。许可关闭时拒绝，开启后返回人工响应，撤销后不再发送请求。真实收费模型调用数为 0。
- AI 获客经营中心的导航、页面、后端实现与接口移除；原本机版本不因此卸载。
- Windows 后台聊天优先 `pythonw.exe`、隐藏窗口，并不使用创建独立控制台的 detached 模式。启动异常仍写日志。
- README 三张图片来自隔离副本真实窗口，不是静态界面或 AI 生成图片。
- 源码采用白名单收集；未打包虚拟环境、node_modules、模型、数据库、日志、个人会话或真实凭证。扫描常见密钥模式未命中。

## 路径核查

原本机相关目录共检查 899 个编程脚本。不能称全部都是相对路径：历史验收脚本仍有固定 `F:/My_AI_System` 默认值（不在发布集合中），另有系统软件扫描使用 Windows 系统目录默认值。工作台原本还依赖固定的虚拟环境子目录和项目锚点。

发布副本将 34 个 Node 文件中的 Python 路径统一为后端根目录解析，支持显式 `WORKBENCH_PYTHON`；前端通过 `WORKBENCH_BACKEND_ROOT` 连接后端，静态资源通过 `WORKBENCH_FRONTEND_ROOT` 定位。安装说明限定已验证的 Windows 范围，不把这些修正称为全部专业工具跨平台可用。

## 限制

Python 基础依赖在新虚拟环境中安装，npm 包按 lockfile 安装。Electron 二进制官方下载在本机遭遇 TLS 连接重置，桌面测试复用本机已有同版本二进制；没有宣称完成另一台实体电脑的全新安装验证。

实际模型服务、用户密钥、外部软件、向量库、CAD 依赖、macOS/Linux 桌面均不在本次验收范围。模型示例不是账户可用性承诺。配套前端现已公开；初次发布阶段的私有访问限制已不适用。

正式候选由本地发布清单逐文件 SHA-256 固定，发布只取受检集合；保留失败与修复记录。回退可选择前一提交；源码回退不删除本机运行数据或替代数据恢复。
